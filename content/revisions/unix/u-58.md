## 개요

### 점검 내용

SNMP 서비스 활성화 여부 점검

### 점검 목적

불필요한 SNMP 서비스를 비활성화하여 필요 이상의 정보가 노출되는 것을 방지하기 위함

### 보안 위협

SNMP 서비스가 활성화되어 있을 경우, 비인가자가 시스템의 중요 정보를 유출하거나 불법적으로 수정할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 불필요한 SNMP 서비스가 비활성화되고 필요한 서비스가 승인 관리 범위로 제한된 경우
- **취약:** 불필요한 SNMP 서비스가 활성화되거나 필요한 서비스의 접근 범위가 제한되지 않은 경우

### 조치 방법

불필요한 SNMP daemon 비활성화 및 필수 모니터링 접근 범위 제한

### 조치 시 영향

모니터링·용량 관리·장애 알림 중단 가능. 에이전트와 trap 수신 역할별 의존성 확인

## 점검 및 조치 사례

### RHEL 10

1. SNMP 패키지 및 실행 역할 확인

   ```bash command
   rpm -q net-snmp
   systemctl cat snmpd.service
   systemctl status snmpd.service snmptrapd.service
   sudo ss -lnup
   ```

2. 에이전트 및 trap 수집 의존성 확인

   UDP 161의 snmpd 에이전트와 UDP 162의 snmptrapd 수신 역할 구분. 실제 실행 인수, 관리망 listen 주소 및 모니터링 등록 상태 확인. 수집 담당자의 사용 근거와 대체 알림 경로 확인

3. 미사용 에이전트 비활성화

   ```bash command
   sudo systemctl disable --now snmpd.service
   systemctl is-active snmpd.service
   systemctl is-enabled snmpd.service
   ```

4. 별도 trap 수신 및 필수 SNMP 통제

   snmptrapd도 사용하지 않는 경우 해당 unit 별도 비활성화. 필요한 SNMP는 관리망·승인 수집기로 제한하고 U-59~61의 인증·비밀정보·조회 권한 통제 적용

5. 수신 포트 및 자동 활성화 확인

   ```bash command
   sudo ss -lnup
   systemctl list-sockets --all
   ```
