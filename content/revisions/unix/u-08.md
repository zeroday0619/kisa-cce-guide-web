## 개정 범위와 판단

관리 권한을 부여하는 모든 그룹과 정책을 최소화한다. GID 0 그룹만 확인하면 실제 sudo 권한을 놓칠 수 있다.

## 배포판별 적용

RHEL 10은 wheel 기반 정책을 확인한다. Ubuntu 26.04 LTS는 sudo-rs가 기본이므로 기존 sudo 확장 옵션의 호환성을 확인한다. Debian 13은 설치된 sudo 구현과 sudo 그룹 정책을 확인한다.

## 점검 절차

`getent group root wheel sudo`와 사용자별 `id USER`, 유효 sudo 권한을 확인한다. LDAP/SSSD 그룹 및 그룹 밖의 sudoers 직접 부여도 조사한다.

## 조치 절차

역할별 승인 사용자만 유지하고 불필요한 관리자 그룹 구성원과 직접 권한을 회수한다. Docker 등 호스트 관리 수준 권한을 주는 그룹은 별도의 특권 목록에 포함한다.

## 영향과 검증

그룹에서 제거해도 기존 세션의 보조 그룹이 즉시 바뀌지 않는다. 활성 세션과 중앙 그룹 캐시를 포함하여 권한 회수 결과를 확인한다.

Verification required: 대상 배포판 VM에서 변경 전후 동작과 복구 절차를 검증해야 한다. 이 문서는 원문과 분리된 개정 초안이며 운영 적용 또는 사람 검토 완료를 의미하지 않는다.
