## 개요

### 점검 내용

불필요한 NFS 서비스 사용 여부 점검

### 점검 목적

NFS(Network File System) 서비스는 한 서버의 파일을 많은 서비스 서버들이 공유하여 사용할 때 이용하는 서비스지만 이를 이용한 침해사고 위험성이 높으므로 사용하지 않는 경우 중지하기 위함

### 보안 위협

NFS 서비스는 서버의 디스크를 클라이언트와 공유하는 서비스로 적정한 보안 설정이 적용되어 있지 않다면 불필요한 파일 공유로 인한 유출 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 불필요한 NFS 서비스 관련 데몬이 비활성화된 경우
- **취약:** 불필요한 NFS 서비스 관련 데몬이 활성화된 경우

### 조치 방법

불필요한 export 제거 및 NFS 서버 서비스 비활성화 설정

### 조치 시 영향

원격 파일 I/O 중단 및 부팅 지연 가능. 사용 중인 NFS 클라이언트 지원 패키지와 마운트 유지

## 점검 및 조치 사례

### RHEL 10

1. NFS 서버 역할 및 클라이언트 의존성 확인

   ```bash command
   rpm -q nfs-utils
   findmnt -t nfs,nfs4
   sudo exportfs -v
   systemctl status nfs-server.service
   ```

2. 사용하지 않는 export 제거

   NFS 클라이언트의 사용 종료 후 `/etc/exports` 및 `/etc/exports.d/*.exports`에서 불필요한 공유 항목 제거. 원격 사용 중인 파일과 마운트 의존성이 없는지 확인 후 변경

3. 공유 변경 적용 및 서버 전체 미사용 시 비활성화

   남은 모든 export가 불필요한 경우에만 아래 서비스 비활성화 명령 실행. 승인된 공유가 남아 있는 경우 export 변경만 적용하고 서버 유지

   ```bash command
   sudo exportfs -ra
   sudo systemctl disable --now nfs-server.service
   ```

4. export 및 클라이언트 마운트 상태 확인

   ```bash command
   sudo exportfs -v
   findmnt -t nfs,nfs4
   sudo ss -lntup
   ```
