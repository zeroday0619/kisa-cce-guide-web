## 개요

### 점검 내용

`/etc/shadow` 파일 권한 적절성 여부 점검

### 점검 목적

`/etc/shadow` 파일을 관리자만 제어할 수 있게 하여 비인가자들의 임의적인 파일 변조를 방지하기 위함

### 보안 위협

`/etc/shadow` 파일에 저장된 암호화된 해시값을 복호화하여(크래킹) 비밀번호를 탈취할 위험이 존재함

### 참고

> **참고**
>
> 개정판은 RHEL의 root 전용 접근과 Ubuntu·Debian의 제한된 shadow 그룹 읽기를 구분하여 판정. 원본의 0400 단일 기준을 배포판 권한 모델로 개정

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** shadow 계열 파일을 root가 소유하고 배포판이 승인한 제한된 인증 주체만 읽으며 비인가 쓰기가 없는 경우
- **취약:** 소유자가 root가 아니거나 일반 사용자에게 읽기·쓰기 또는 불필요한 ACL 권한이 부여된 경우

### 조치 방법

shadow 계열 파일을 root 소유로 유지하고 root 및 배포판 인증에 필요한 제한된 주체 외의 읽기·쓰기 제거

### 조치 시 영향

Ubuntu·Debian의 shadow 그룹 읽기를 일괄 제거하면 인증 보조 프로그램에 영향이 있을 수 있으므로 배포판 접근 모델 유지

## 점검 및 조치 사례

### RHEL 10

1. 해시 내용을 출력하지 않고 shadow 계열 파일의 소유자·모드·ACL 확인

   ```bash command
   sudo stat -c '%U %G %a %n' /etc/shadow /etc/gshadow /etc/shadow- /etc/gshadow-
   sudo getfacl -p /etc/shadow /etc/gshadow
   ```

2. RHEL의 root 전용 접근 기준으로 소유자 및 모드 복구. 인증 패키지가 별도 모드를 관리하는 경우 설치 패키지 정책과 대조

   ```bash command
   rpm -qf /etc/shadow /etc/gshadow
   ```

3. 확인한 배포판 소유자·그룹·모드로 실제 인증 파일 복구

   ```bash command
   sudo chown root:root /etc/shadow /etc/gshadow
   sudo chmod 0000 /etc/shadow /etc/gshadow
   ```

4. 백업 파일도 동일하거나 더 제한된 읽기 정책으로 관리하고 비인가 명명 ACL 제거. 파일이 없으면 불필요하게 생성하지 않음

5. 계정 파일 일관성과 별도 세션의 로그인·비밀번호 변경 확인

   ```bash command
   sudo pwck -r
   sudo grpck -r
   ```

### Ubuntu 26.04 LTS

1. 해시 내용을 출력하지 않고 shadow 계열 파일의 소유자·모드·ACL 확인

   ```bash command
   sudo stat -c '%U %G %a %n' /etc/shadow /etc/gshadow /etc/shadow- /etc/gshadow-
   sudo getfacl -p /etc/shadow /etc/gshadow
   ```

2. shadow 그룹 구성원 및 해당 그룹으로 실행되는 인증 도구 확인. 불필요한 사용자에게 shadow 그룹 부여 금지

   ```bash command
   getent group shadow
   getent passwd | awk -F: '{print $1, $4}'
   ```

3. 확인한 배포판 소유자·그룹·모드로 실제 인증 파일 복구

   ```bash command
   sudo chown root:shadow /etc/shadow /etc/gshadow
   sudo chmod 0640 /etc/shadow /etc/gshadow
   ```

4. 백업 파일도 동일하거나 더 제한된 읽기 정책으로 관리하고 비인가 명명 ACL 제거. 파일이 없으면 불필요하게 생성하지 않음

5. 계정 파일 일관성과 별도 세션의 로그인·비밀번호 변경 확인

   ```bash command
   sudo pwck -r
   sudo grpck -r
   ```
