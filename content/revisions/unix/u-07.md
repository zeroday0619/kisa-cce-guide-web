## 개요

### 점검 내용

시스템 계정 중 불필요한 계정(퇴직, 전직, 휴직 등의 이유로 사용하지 않는 계정 및 장기적으로 사용하지 않는 계정 등)이 존재 여부 점검

### 점검 목적

불필요한 계정이 존재하는지 점검하여 관리되지 않은 계정에 의한 침입에 대비하는지 확인하기 위함

### 보안 위협

로그인이 가능하고 현재 사용하지 않는 불필요한 계정은 사용 중인 계정보다 상대적으로 관리가 취약하여 공격자의 목표가 되어 계정이 탈취될 수 있는 위험이 존재함(퇴직, 전직, 휴직 등의 사유 발생 시 즉시 권한을 회수하는 것을 권고함)

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 불필요한 계정이 존재하지 않는 경우
- **취약:** 불필요한 계정이 존재하는 경우

### 조치 방법

계정의 업무 필요성과 소유 데이터를 확인한 후 불필요한 계정 및 해당 인증 수단 제거

### 조치 시 영향

계정 제거 시 배치·백업·애플리케이션 실행에 영향이 있으므로 파일 소유권 인계 및 보존 확인 필요. 홈 디렉터리 삭제를 계정 제거와 일괄 수행하지 않음

## 점검 및 조치 사례

### RHEL 10

1. 계정 목록과 업무 소유자 대장 대조

   ```bash command
   getent passwd
   systemctl list-units --type=service --state=running
   loginctl list-sessions
   ```

2. 삭제 후보의 실행 프로세스·예약 작업·서비스 실행 사용자 확인. `USER`와 `UNIT`은 조사 대상 계정과 서비스로 대체

   ```bash command
   id USER
   ps -u USER -f
   sudo crontab -u USER -l
   systemctl show UNIT -p User -p Group
   ```

3. 불필요한 개인 계정의 SSH 키·인증서·중앙 인증 및 토큰 회수 후 활성 세션 종료. 비밀번호 잠금만으로 키 인증 차단 여부 판단 금지

   ```bash command
   sudo usermod -L -e 1 USER
   sudo loginctl terminate-user USER
   ```

4. 파일 소유권 인계 및 예약 작업 정리 후 로컬 계정 삭제. 패키지 서비스 계정은 해당 서비스의 제거 계획에 따라 처리

   ```bash command
   sudo userdel USER
   getent passwd USER
   ```
