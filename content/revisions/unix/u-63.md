## 개정 범위와 판단

sudo 정책은 파일 보호와 실제 위임 권한을 함께 관리한다. 파일 모드 0640만으로 최소 권한을 충족했다고 판정하지 않는다.

## 배포판별 적용

RHEL 10은 wheel 기반 정책을 확인한다. Ubuntu 26.04 LTS는 sudo-rs가 기본이므로 기존 sudo 확장 옵션의 호환성을 확인한다. Debian 13은 설치된 sudo 구현과 sudo 그룹 정책을 확인한다.

## 점검 절차

설치된 sudo 구현·`sudo --version`, `/etc/sudoers`와 include 디렉터리, 사용자별 유효 허용 명령을 확인한다. `visudo -c` 지원과 검사 결과를 확인하고 정책 파일의 root 소유·ACL도 조사한다.

## 조치 절차

배포판의 기본 제한 모드인 0440 등을 유지하고 비인가 쓰기를 제거한다. 불필요한 ALL·NOPASSWD·광범위한 인수 허용을 축소하며 수정은 해당 구현이 지원하는 검증 도구로 검사한다.

## 영향과 검증

Ubuntu 26.04의 sudo-rs와 기존 sudo의 옵션·플러그인 호환성을 확인한다. 잘못된 정책은 관리 권한을 잃게 하므로 별도 복구 세션과 허용·거부 시험을 유지한다.

Verification required: 대상 배포판 VM에서 변경 전후 동작과 복구 절차를 검증해야 한다. 이 문서는 원문과 분리된 개정 초안이며 운영 적용 또는 사람 검토 완료를 의미하지 않는다.
