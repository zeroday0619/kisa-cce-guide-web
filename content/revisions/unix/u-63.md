## 개요

### 점검 내용

sudo 정책 파일 보호 및 관리자 권한 위임의 적절성 여부 점검

### 점검 목적

비인가자가 관리자 권한을 남용하여 시스템 손상, 악성 코드 실행, 민감한 데이터 유출 등의 보안 위협을 방지하기 위함

### 보안 위협

`sudo` 명령어 접근을 제한하지 않을 경우, 비인가자가 관리자 권한으로 허가되지 않은 명령어를 사용하여 루트 권한 오용, 악성 코드 실행, 데이터 유출 등의 시도를 할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** sudo 정책 파일이 root 소유로 보호되고 승인된 사용자와 명령만 위임된 경우
- **취약:** sudo 정책 파일의 비인가 변경이 가능하거나 불필요한 관리자 권한이 위임된 경우

### 조치 방법

sudoers 및 포함 파일 보호와 승인 사용자·명령의 최소 권한 설정

### 조치 시 영향

구문 오류 또는 권한 축소 시 관리 권한 상실 가능. 별도 복구 세션 유지

## 점검 및 조치 사례

### RHEL 10

1. sudo 구현 및 정책 파일 확인

   ```bash command
   sudo --version
   sudo visudo -c
   sudo stat -c '%U:%G %a %n' /etc/sudoers
   sudo find /etc/sudoers.d -maxdepth 1 -type f -ls
   getent group wheel
   ```

2. 사용자별 유효 위임 권한 확인

   `sudo -l -U USER`에서 실제 승인 사용자 권한 확인. USER는 점검 대상 계정으로 대체. include 파일의 ALL, NOPASSWD 및 광범위한 명령 인수 허용 여부 확인. 현재 wheel 그룹 구성과 사용자별 정책 대조

3. sudoers 보호 권한 적용

   ```bash command
   sudo chown root:root /etc/sudoers
   sudo chmod 0440 /etc/sudoers
   sudo visudo
   ```

4. 포함 파일 및 최소 위임 권한 조정

   `visudo -f /etc/sudoers.d/FILE`로 해당 파일만 편집하여 승인 계정·명령·인수 범위로 제한. FILE은 실제 정책 파일명으로 대체. 포함 파일도 root 소유 및 비인가 쓰기 금지 적용하고 ACL 확인. 셸·편집기 등 임의 명령 실행이 가능한 위임은 실제 관리자 권한으로 평가

5. 전체 구문 검사

   ```bash command
   sudo visudo -c
   ```

6. 관리 접근과 권한 제한 확인

   별도 root 복구 세션을 유지하고 새 세션에서 승인된 명령 성공 및 비승인 명령 거부 확인. 설정 검사 성공만으로 최소 권한 충족으로 판단 금지
