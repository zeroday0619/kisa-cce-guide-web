## 개요

### 점검 내용

숨겨진 파일 및 디렉토리 내 의심스러운 파일 존재 여부 점검

### 점검 목적

숨겨진 파일 및 디렉토리 중 의심스러운 내용은 정상 사용자가 아닌 공격자에 의해 생성되었을 가능성이 높으므로 이를 제거하여 보안 위협을 방지하기 위함

### 보안 위협

숨겨진 파일 및 디렉토리를 방치할 경우, 비인가자가 생성한 악성 파일 또는 백도어 등을 탐지하지 못할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 숨김 파일·디렉터리의 용도를 확인하고 불필요하거나 침해가 의심되는 객체를 적절히 처리한 경우
- **취약:** 용도 불명 또는 침해가 의심되는 숨김 객체를 조사 없이 방치한 경우

### 조치 방법

숨김 객체의 생성 근거와 필요성을 확인하고 불필요한 파일은 개별 정리하며 침해 의심 파일은 증거 보존 후 처리

### 조치 시 영향

숨김 파일 일괄 삭제 시 SSH 인증키·사용자 설정·애플리케이션 데이터가 손실될 수 있으므로 정상 용도 확인 후 처리

## 점검 및 조치 사례

### RHEL 10

1. 승인된 사용자 홈 및 애플리케이션 경로에서 숨김 객체 목록 확인. `/srv/data`는 점검 대상으로 대체

   ```bash command
   sudo find /srv/data -xdev -name '.*' -ls
   ```

2. 의심 객체의 소유자·파일 유형·변경 시각 및 패키지 소속 확인. `/PATH/.FILE`은 실제 조사 대상으로 대체

   ```bash command
   stat /PATH/.FILE
   file /PATH/.FILE
   rpm -qf /PATH/.FILE
   ```

3. `.ssh`·`.config`·`.local` 등 정상 설정 및 애플리케이션 데이터를 소유자·변경 관리 기록과 대조. 숨김 여부만으로 불필요한 파일 판정 금지

4. 불필요한 객체는 소유자의 보존 요구 확인 후 개별 정리. 침해가 의심되는 객체는 해시·metadata·원본을 보존하고 사고 대응 절차에 따라 격리

   ```bash command
   sudo sha256sum /PATH/.FILE
   ```

5. 동일 경로 재검색 및 로그인·애플리케이션 정상 실행 확인. 생성 프로세스가 남아 있으면 원인 설정도 함께 처리
