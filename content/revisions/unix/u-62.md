## 개요

### 점검 내용

서버 및 서비스에 로그온 시 불필요한 정보 차단 설정 및 불법적인 사용에 대한 경고 메시지 출력 여부 점검

### 점검 목적

비인가자들에게 서버에 대한 불필요한 정보를 제공하지 않고, 서버 접속 시 관계자만 접속해야 한다는 경각심을 심어 주기 위함

### 보안 위협

로그온 시 경고 메시지가 설정되어 있지 않을 경우, 기본 설정값엔 서버 OS 버전 및 서비스 버전이 비인가자에게 노출되어 해당 정보를 통해 서비스의 취약점을 이용하여 공격을 시도할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** SSH·콘솔 등 로그인 경로에 승인 경고가 표시되고 불필요한 시스템 정보가 노출되지 않는 경우
- **취약:** 로그인 경고가 없거나 불필요한 시스템 정보가 노출되는 경우

### 조치 방법

SSH 및 콘솔의 인증 전 경고 문안 설정과 불필요한 시스템 정보 제거

### 조치 시 영향

자동화 클라이언트의 출력 처리 영향 가능. 인증 전 표시와 문자 인코딩 확인

## 점검 및 조치 사례

### RHEL 10

1. SSH 인증 전 배너의 유효 설정 확인

   ```bash command
   sudo sshd -T | grep '^banner '
   systemctl cat getty@.service
   ```

2. 승인된 경고 문안 설정

   ```text configuration
   This system is for authorized users only.
   Unauthorized access is prohibited.
   Activities may be recorded in accordance with organizational policy.
   ```

3. 배너 파일 및 콘솔 문안 반영

   승인 문안을 `/etc/issue.net`에 저장하고 root 소유 및 비인가 쓰기 금지 적용. 콘솔은 실제 getty가 사용하는 `/etc/issue` 등에 동일 목적의 문안 설정. 운영체제·제품 버전·내부 호스트명과 개인정보 제외

4. SSH 인증 전 배너 경로 지정

   ```text configuration
   Banner /etc/issue.net
   ```

5. 유효 설정 위치 확인

   `/etc/ssh/sshd_config`의 `Include /etc/ssh/sshd_config.d/*.conf` 활성 여부와 위치 확인 후 역할별 `/etc/ssh/sshd_config.d/40-login-banner.conf`에 Banner 설정. 포함 파일은 사전식 순서로 읽고 먼저 얻은 값이 적용되므로 더 이른 파일과 Include 앞의 Banner 정의 정리. 파일 번호만으로 우선 적용을 보장하지 않으며 Match 조건의 배너도 별도 대조. `sshd -T -C user=USER,host=HOST,addr=ADDR`에서 USER·HOST·ADDR을 실제 접속 조건으로 대체하여 유효 Banner 확인. 로그인 후 표시되는 MOTD만으로 인증 전 경고를 대체하지 않도록 설정

6. SSH 구문 검사 및 적용

   ```bash command
   sudo sshd -t
   sudo systemctl reload sshd.service
   sudo sshd -T | grep '^banner '
   ```

7. 실제 표시 시점 확인

   신규 SSH 연결에서 인증 전 경고와 콘솔 로그인 화면의 경고 확인. 자동화 클라이언트 출력 처리 영향 확인. 로그인 개념이 없는 DNS에 임의 경고 배너 추가 금지
