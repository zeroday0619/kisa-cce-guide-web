## 개요

### 점검 내용

NTP 및 시각 동기화 설정 여부 점검

### 점검 목적

인증 및 감사 목적을 위한 시간 동기화는 필수적이며, 안전하고 승인된 NTP 서비스와 동기화하기 위함

### 보안 위협

시스템 간 시간 동기화 미흡으로 보안 사고 및 장애 발생 시 로그에 대한 신뢰도 확보 미흡 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 승인 시간원으로 실제 동기화되고 조직의 허용 시간 오차를 충족한 경우
- **취약:** 비승인 시간원을 사용하거나 동기화 실패 또는 허용 시간 오차 초과 상태인 경우

### 조치 방법

승인 시간원 설정 및 실제 동기화 상태·시간 오차 관리

### 조치 시 영향

시간 급변 시 Kerberos·인증서·로그 순서·DB 영향 가능. 초기 보정과 운영 중 보정 정책 구분

## 점검 및 조치 사례

### RHEL 10

1. 실제 시간 동기화 서비스 및 상태 확인

   ```bash command
   timedatectl status
   systemctl list-units --type=service --all | grep -E "chrony|chronyd|timesyncd|ntp"
   chronyc tracking
   chronyc sources -v
   ```

2. 유효 시간원 설정 확인

   `/etc/chrony.conf`의 `include`, `confdir`, `sourcedir`에서 승인 시간원, 중복 설정 및 네트워크 도달성 확인. `confdir`는 사전식 순서의 `*.conf`, `sourcedir`는 시간원 전용 `*.sources`를 읽으므로 파일 확장자와 활성 포함 경로 확인. chronyd 실행 인수와 설치 설정 기준으로 점검

3. 승인된 시간원 설정 예시

   ```text configuration
   server time1.example.net iburst
   server time2.example.net iburst
   ```

4. 시간원 및 인증 방식 반영

   예시 호스트를 조직의 승인된 시간원으로 대체하여 관리자가 분리한 역할별 경로 `/etc/chrony.d/sources.d/60-approved.sources`에 저장. 이 경로는 기본 제공 경로가 아닌 구성 예시이며 상위 디렉터리를 root 소유로 생성하고 서비스 읽기 권한과 SELinux 파일 레이블 확인. 시간원 파일에는 server·pool·peer만 작성하고 각 행을 개행으로 종료. 일반 정책은 `/etc/chrony.d/conf.d/60-time-policy.conf`로 분리하고 `/etc/chrony.conf`에 `sourcedir /etc/chrony.d/sources.d`와 `confdir /etc/chrony.d/conf.d`가 없으면 추가. 디렉터리 존재만으로 자동 로드되지 않으며 기존 비승인 시간원이 새 파일로 대체되는 것으로 판단 금지. 기존 비승인 server·pool 및 동적 공급 경로 정리. NTS 지원 시간원 사용 시 인증서 신뢰와 네트워크를 구성한 후 `nts` 옵션 적용. 필요한 서버 역할이 없으면 클라이언트 접근을 허용하는 allow 설정 제외

5. chrony 설정 적용 및 동기화 상태 확인

   `chronyd -p`의 include·confdir 구문 검사 성공 후 재시작. sourcedir 시간원의 실제 반영은 재시작 후 `chronyc sources -v`로 확인

   ```bash command
   sudo chronyd -p -f /etc/chrony.conf
   sudo systemctl restart chronyd.service
   chronyc tracking
   chronyc sources -v
   ```

6. 시간 오차 및 중복 daemon 확인

   선택된 시간원, 도달 상태, Leap status와 조직 허용 오차 확인. systemd-timesyncd 사용 시 `timedatectl timesync-status` 및 해당 설정 경로로 확인. 동시에 여러 daemon이 시스템 시간을 조정하지 않도록 설정. 운영 중 강제 시간 점프 전 인증·DB 영향 확인
