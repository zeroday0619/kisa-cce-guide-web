## 개요

### 점검 내용

불필요한 RPC 서비스의 실행 여부 점검

### 점검 목적

많은 취약점(버퍼 오버플로우, DoS, 원격 실행 등)이 존재하는 RPC 서비스를 비활성화하여 시스템의 보안성을 높이기 위함

### 보안 위협

RPC 서비스의 취약점을 통해 비인가자가 root 권한 획득 및 각종 공격을 시도할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 불필요한 RPC 서비스가 비활성화된 경우
- **취약:** 불필요한 RPC 서비스가 활성화된 경우

### 조치 방법

불필요한 RPC 서비스와 활성화 socket 비활성화 설정

### 조치 시 영향

NFSv3 및 스토리지 잠금·복구 중단 가능. rpcbind 종속성 확인 후 적용

## 점검 및 조치 사례

### RHEL 10

1. RPC 등록 서비스 및 종속성 확인

   ```bash command
   sudo rpcinfo -p localhost
   systemctl status rpcbind.service rpcbind.socket
   systemctl list-dependencies --reverse rpcbind.service
   findmnt -t nfs,nfs4
   ```

2. RPC별 사용 목적 및 활성화 경로 확인

   등록 프로그램을 실제 실행 프로세스와 대조하여 NFS, 파일 잠금, quota 및 구형 사용자 정보 서비스 구분. `rpcinfo` 미설치 또는 조회 오류는 서비스 미사용과 구분

3. 불필요한 RPC 서비스 비활성화

   발견된 RPC 서비스별 unit 또는 inetd 항목 비활성화. NFSv3 등 rpcbind 의존성이 없는 경우에만 아래 명령으로 service와 socket 함께 중지

4. rpcbind 미사용 시 활성화 경로 차단

   ```bash command
   sudo systemctl disable --now rpcbind.socket rpcbind.service
   systemctl is-active rpcbind.socket rpcbind.service
   systemctl is-enabled rpcbind.socket rpcbind.service
   ```

5. 스토리지 종속 기능 확인

   NFS 마운트, 파일 잠금, 재접속 및 복구 동작 확인. 필요한 RPC는 승인 네트워크로 접근 제한하고 서비스 패치 유지
