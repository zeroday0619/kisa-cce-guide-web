## 개요

### 점검 내용

비밀번호 관리 정책 설정 여부 점검

### 점검 목적

사용자의 비밀번호 복잡성과 주기적 변경을 통해 시스템 보안을 강화하기 위함

### 보안 위협

비밀번호 관련 정책이 설정되지 않을 경우, 비인가자의 각종 공격(무차별 대입 공격, 사전 대입 공격 등)에 의해 비밀번호가 노출될 위험이 존재함

### 참고

> **참고**
>
> 중앙 인증 계정의 품질·이력·만료 정책은 해당 인증 공급자에서 적용. 로컬 `pam_pwhistory`의 이력을 여러 서버의 중앙 비밀번호 이력으로 사용하지 않음

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 비밀번호 관리 정책이 설정된 경우
- **취약:** 비밀번호 관리 정책이 설정되지 않은 경우

### 조치 방법

root 계정을 포함한 로컬 사용자 비밀번호에 영문·숫자·특수문자 포함 최소 8자, 최소 사용 기간 1일, 최대 사용 기간 90일, 최근 비밀번호 기억 4회 이상 설정

### 조치 시 영향

비밀번호 변경 및 만료 시 Web, WAS, DB 연동 구간에 영향이 있으므로 서비스 계정의 변경 일정 조정 필요. PAM 변경 전 복구 가능한 관리 세션 유지

## 점검 및 조치 사례

### RHEL 10

1. 현재 인증 profile, feature 및 PAM password stack 확인

   ```bash command
   sudo authselect current
   sudo authselect check
   grep -nE 'pam_(pwquality|pwhistory|unix)' /etc/pam.d/system-auth /etc/pam.d/password-auth
   ```

2. 현재 profile이 `with-pwhistory`를 지원하는지 확인한 후 feature 활성화. 생성된 PAM 파일 직접 수정 금지

   ```bash command
   sudo authselect enable-feature with-pwhistory
   sudo authselect check
   ```

3. `/etc/security/pwquality.conf`의 다음 기준 확인 및 설정. `pwquality.conf.d` 포함 파일과 PAM 모듈 인수를 함께 확인하여 기존의 더 강한 정책 유지

   ```text configuration
   minlen = 8
   minclass = 3
   dcredit = -1
   ocredit = -1
   ucredit = 0
   lcredit = 0
   enforce_for_root
   ```

4. `/etc/security/pwhistory.conf`에 최근 비밀번호 기억 횟수 및 root 적용 설정

   ```text configuration
   remember = 4
   enforce_for_root
   ```

5. `/etc/login.defs`에 신규 계정의 비밀번호 사용 기간 설정

   ```text configuration
   PASS_MIN_DAYS 1
   PASS_MAX_DAYS 90
   ```

6. 기존 로컬 사용자별 사용 기간 확인 후 적용. `USER`는 변경 대상 계정으로 대체하며 중앙 인증 계정은 인증 공급자에서 설정

   ```bash command
   sudo chage -l USER
   sudo chage -m 1 -M 90 USER
   sudo chage -l USER
   ```

7. 별도 시험 계정의 비밀번호 변경으로 길이·문자 종류·재사용 거부 확인. root 변경 경로에도 품질 및 이력 정책 적용 여부 확인

### Ubuntu 26.04 LTS

1. 설치된 PAM 모듈과 비밀번호 변경 profile 확인. `libpam-pwquality`가 없는 경우 설치

   ```bash command
   dpkg-query -W libpam-runtime libpam-modules libpam-pwquality
   grep -nE 'pam_(pwquality|pwhistory|unix)' /etc/pam.d/common-password
   sudo apt install libpam-pwquality
   ```

2. `pam-auth-update`에서 비밀번호 품질 profile 활성화. 로컬 계정의 이력 관리용 `/usr/share/pam-configs/local-pwhistory` 파일 작성

   ```text configuration
   Name: Local password history
   Default: yes
   Priority: 1000
   Password-Type: Primary
   Password:
           requisite pam_pwhistory.so use_authtok
   ```

3. profile 적용 후 `common-password`에서 `pam_pwquality` → `pam_pwhistory` → `pam_unix ... use_authtok` 순서 및 기존 중앙 인증 경로 보존 확인


4. `/etc/security/pwquality.conf`의 다음 기준 확인 및 설정. `pwquality.conf.d` 포함 파일과 PAM 모듈 인수를 함께 확인하여 기존의 더 강한 정책 유지
