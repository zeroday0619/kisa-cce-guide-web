## 개요

### 점검 내용

SMTP 서비스 사용 시 `expn`, `vrfy` 명령어 사용 금지 설정 여부 점검

### 점검 목적

SMTP 서비스의 `expn`, `vrfy` 명령을 통한 정보 유출을 방지하기 위함

### 보안 위협

`expn`, `vrfy` 명령어를 통하여 특정 사용자 계정의 존재 여부를 알 수 있고, 사용자의 정보를 외부로 유출할 수 있는 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** `noexpn`, `novrfy` 옵션이 설정된 경우
- **취약:** `noexpn`, `novrfy` 옵션이 설정되어 있지 않은 경우

### 조치 방법

메일 구현의 EXPN·VRFY 사용자 정보 조회 기능 제한

### 조치 시 영향

메일 진단 도구 영향 가능. 수신자 검증 응답까지 모두 은닉되는 것으로 판단 금지

## 점검 및 조치 사례

### RHEL 10

1. 사용 중인 SMTP 구현과 유효 VRFY 설정 확인

   ```bash command
   sudo postconf mail_version disable_vrfy_command
   sudo postconf -M
   sudo postconf -P
   ```

2. Postfix VRFY 비활성화

   ```bash command
   sudo postconf -e "disable_vrfy_command = yes"
   sudo postfix check
   sudo postfix reload
   ```

3. 적용된 설정 확인

   ```bash command
   sudo postconf disable_vrfy_command
   ```

4. 구현별 열거 기능 제한 확인

   `master.cf`의 서비스별 override에서 VRFY가 재허용되지 않는지 확인. Postfix에서 제공하지 않는 EXPN 기능에 Sendmail 옵션 추가 금지. Exim·Sendmail은 실제 지원되는 EXPN·VRFY 접근 정책으로 제한. 진단 도구와 정상 메일 수신 영향 확인
