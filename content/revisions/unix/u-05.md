## 개정 범위와 판단

호스트의 UID 0은 승인된 root 계정 하나로 제한한다. 컨테이너 user namespace의 UID 매핑은 호스트 계정과 분리하여 평가한다.

## 배포판별 적용

RHEL 10, Ubuntu 26.04 LTS, Debian 13의 설치 패키지와 실제 실행 구성을 대상으로 한다. 파생 배포판·컨테이너·중앙 관리 환경은 동일한 이름만으로 적용성을 추정하지 않고 해당 관리 경로를 확인한다.

## 점검 절차

`getent passwd` 결과에서 세 번째 필드가 0인 계정을 확인하고 `/etc/passwd`와 대조한다. 중앙 디렉터리가 열거를 제한하면 해당 인증 공급자의 조회 결과도 확보한다.

## 조치 절차

중복 관리자 계정은 고유 UID의 개인 계정과 필요한 sudo 권한으로 이전한다. 사용 프로세스·파일·예약 작업·원격 저장소 소유권을 목록화한 뒤 지원되는 사용자 관리 도구로 수정한다.

## 영향과 검증

UID 변경은 파일의 숫자 소유자를 자동으로 모두 변경하지 않는다. 원격 파일시스템과 실행 중 세션을 포함하여 소유권 이전을 검증한다.

Verification required: 대상 배포판 VM에서 변경 전후 동작과 복구 절차를 검증해야 한다. 이 문서는 원문과 분리된 개정 초안이며 운영 적용 또는 사람 검토 완료를 의미하지 않는다.
