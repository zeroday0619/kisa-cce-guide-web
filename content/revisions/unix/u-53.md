## 개요

### 점검 내용

FTP 서비스 정보 노출 여부 점검

### 점검 목적

FTP 서비스 접속 배너를 통한 불필요한 정보 노출을 방지하기 위함

### 보안 위협

서비스 접속 배너가 차단되지 않을 경우, 비인가자가 FTP 접속 시도 시 노출되는 접속 배너 정보를 수집하여 악의적인 공격에 이용할 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** FTP를 사용하지 않거나 접속 배너에 불필요한 제품·버전·내부 정보가 없는 경우
- **취약:** FTP 접속 배너에 불필요한 제품·버전·내부 정보가 노출되는 경우

### 조치 방법

FTP 접속 배너에서 불필요한 제품·버전·내부 정보 제거

### 조치 시 영향

배너 문자열에 의존하는 클라이언트 영향 가능. FTP 상태 코드 및 정상 연결 유지

## 점검 및 조치 사례

### RHEL 10

1. FTP 구현 및 실제 설정 경로 확인

   ```bash command
   rpm -q vsftpd
   systemctl cat vsftpd.service
   sudo ss -lntp
   ```

2. 설정 변경 전 기존 항목 확인

   `/etc/vsftpd/vsftpd.conf` 및 daemon 실행 인수에서 실제 설정 경로 확인. 중복 설정과 별도 인스턴스를 포함하여 ftpd_banner 및 banner_file의 내용 확인

3. vsftpd 설정 수정

   ```text configuration
   ftpd_banner=Authorized access only.
   ```

4. 설정 경로 및 운영 조건 반영

   `/etc/vsftpd/vsftpd.conf`의 해당 항목 수정. `banner_file`이 지정된 경우 해당 파일의 문구가 우선하므로 파일에서도 제품명·버전·내부 호스트명 제거. 실제 접속 배너의 안내 문구와 정상 연결 확인

5. 서비스 재시작 및 실행 상태 확인

   ```bash command
   sudo systemctl restart vsftpd.service
   systemctl status vsftpd.service
   sudo journalctl -u vsftpd.service -n 30 --no-pager
   ```
