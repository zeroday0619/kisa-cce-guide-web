## 개요

### 점검 내용

Finger 서비스 비활성화 여부 점검

### 점검 목적

Finger 서비스를 통해 네트워크 외부에서 해당 시스템에 등록된 사용자 정보를 확인할 수 있어 비인가자에게 사용자 정보가 조회되는 것을 방지하기 위함

### 보안 위협

Finger 서비스가 활성화되어 있을 경우, 비인가자가 Finger 서비스를 사용하여 사용자 정보를 조회한 후 비밀번호 공격을 통해 계정을 탈취할 위험이 존재함

### 참고

> **참고**
>
> Finger 클라이언트 설치와 Finger 서버 실행 상태를 구분하여 점검

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** Finger 서비스가 비활성화된 경우
- **취약:** Finger 서비스가 활성화된 경우

### 조치 방법

Finger 서버 서비스 및 활성화 socket 비활성화 설정

### 조치 시 영향

Finger 사용자 정보 조회 기능 중단. 다른 inetd 서비스의 영향 여부 확인

## 점검 및 조치 사례

### RHEL 10

1. 설치된 서버 패키지 및 서비스 활성화 경로 확인

   ```bash command
   rpm -qa | grep -Ei 'finger'
   systemctl list-unit-files | grep -Ei 'finger'
   systemctl list-sockets --all
   sudo ss -lntup
   ```

2. 표준 포트 및 별도 실행 설정 확인

   TCP 79의 수신 프로세스와 실행 인수 확인. `/etc/inetd.conf`, `/etc/xinetd.d/`가 존재하는 경우 해당 서비스 항목 확인. 패키지 미설치 및 포트 부재만으로 비활성 여부를 판단하지 않고 사용자 지정 서비스도 확인

3. 불필요한 서버 활성화 설정 제거

   확인된 서비스와 socket 이름을 지정하여 `systemctl disable --now UNIT` 실행. `UNIT`은 실제 해당 unit 이름으로 대체. inetd는 해당 항목 주석 처리, xinetd는 해당 항목의 `disable = yes` 설정 후 사용 중인 관리자 서비스 재시작. 다른 서비스를 함께 제공하는 inetd 전체 중지 금지

4. 서비스 및 socket 재활성화 여부 확인

   ```bash command
   systemctl list-units --all | grep -Ei 'finger'
   systemctl list-sockets --all
   sudo ss -lntup
   ```
