## 개요

### 점검 내용

autofs 및 systemd automount의 필요성과 설정 적절성 여부 점검

### 점검 목적

불필요한 자동 마운트를 제한하여 비인가 파일시스템 접근을 방지하기 위함

### 보안 위협

자동 마운트 대상과 설정 파일의 접근 통제가 미흡할 경우, 비인가 파일시스템 연결 및 악성 파일 접근의 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 불필요한 자동 마운트가 비활성화되고 필요한 대상이 승인된 서버와 경로로 제한된 경우
- **취약:** 불필요한 자동 마운트가 활성화되거나 승인되지 않은 서버와 경로를 마운트하는 경우

### 조치 방법

불필요한 autofs map 및 systemd automount 비활성화 설정

### 조치 시 영향

중앙 홈 로그인과 공유 파일 접근 중단 가능. 열린 파일과 재접근 동작 확인

## 점검 및 조치 사례

### RHEL 10

1. 자동 마운트 및 사용 중인 파일시스템 확인

   ```bash command
   systemctl status autofs.service
   systemctl list-units --type=automount --all
   findmnt
   grep -n 'x-systemd.automount' /etc/fstab
   ```

2. 자동 마운트 map과 소비 서비스 확인

   `/etc/auto.master`, `/etc/auto.master.d/` 및 참조 map에서 자동 마운트 대상 확인. LDAP·SSSD 기반 중앙 홈과 백업 경로의 사용 여부 확인. systemd automount는 `systemctl cat UNIT.automount`로 생성 경로 확인

3. autofs 미사용 시 비활성화

   ```bash command
   sudo systemctl disable --now autofs.service
   ```

4. 불필요한 systemd automount 제거

   사용 종료된 대상의 `.automount` unit을 중지하고 활성화 해제. `/etc/fstab` 생성 unit이면 해당 항목을 운영 목적에 맞게 수정하고 `systemctl daemon-reload` 실행. 사용 중인 중앙 홈이나 필수 마운트는 승인 서버·경로로 제한하여 유지

5. 재활성화 및 필수 마운트 확인

   ```bash command
   systemctl list-units --type=automount --all
   findmnt
   ```
