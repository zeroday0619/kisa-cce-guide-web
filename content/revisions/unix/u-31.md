## 개요

### 점검 내용

홈 디렉토리의 소유자 외 타 사용자가 해당 홈 디렉토리를 수정할 수 없도록 제한 설정 여부 점검

### 점검 목적

사용자 홈 디렉토리 내 설정 파일이 비인가자에 의한 변조를 방지하기 위함

### 보안 위협

홈 디렉토리 내 설정 파일 변조 시 정상적인 서비스 이용이 제한될 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 개인 홈을 해당 계정이 소유하고 타 사용자 쓰기가 제거되었거나 chroot 등 승인된 관리 소유권을 유지하는 경우
- **취약:** 홈 소유권이 승인 모델과 다르거나 비인가 사용자가 홈을 변경할 수 있는 경우

### 조치 방법

개인 홈의 소유자를 해당 사용자로 유지하고 타 사용자 쓰기를 제거하며 공유·chroot 홈은 승인된 소유권 모델 적용

### 조치 시 영향

재귀 chown 또는 공유 홈 권한 변경 시 SFTP chroot 및 공동 작업에 장애가 발생할 수 있으므로 실제 홈과 마운트 확인 후 조치

## 점검 및 조치 사례

### RHEL 10

1. 계정의 실제 홈과 경로·마운트 상태 확인. `USER` 및 `/home/USER`는 조회한 값으로 대체

   ```bash command
   getent passwd USER
   namei -l /home/USER
   findmnt -T /home/USER
   ```

2. 홈 디렉터리의 소유자 및 기본·명명 ACL 확인

   ```bash command
   stat -c "%U %G %a %n" /home/USER
   getfacl -p /home/USER
   ```

3. 일반 개인 홈의 소유자를 해당 계정으로 지정하고 타 사용자 쓰기 제거. SFTP chroot·공유 홈·중앙 홈은 해당 설계의 소유권 유지

   ```bash command
   sudo chown USER /home/USER
   sudo chmod go-w /home/USER
   sudo restorecon -v /home/USER
   ```

4. 비인가 명명 ACL의 쓰기 권한도 제거하고 새 로그인에서 홈 접근·파일 생성 확인. 하위 파일에 대한 일괄 재귀 소유권 변경 금지
