## 개요

### 점검 내용

로그인이 불필요한 계정(adm, sys, daemon 등)에 쉘 부여 여부 점검

### 점검 목적

로그인이 불필요한 계정에 부여된 쉘을 제거하여, 로그인이 필요하지 않은 계정을 통한 시스템 명령어를 실행하지 못하게 하기 위함

### 보안 위협

로그인이 불필요한 계정에 쉘이 부여될 경우, 비인가자가 해당 기본 계정으로 시스템에 접근 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 로그인이 필요하지 않은 계정에 `nologin` 또는 `/bin/false` shell을 부여하고 대화형 접속을 제한한 경우
- **취약:** 로그인이 필요하지 않은 계정에 대화형 shell을 허용한 경우

### 조치 방법

대화형 로그인이 필요하지 않은 서비스 계정에 배포판의 `nologin` shell 부여

### 조치 시 영향

shell을 실행하는 배치 및 파일 전송에 영향이 있을 수 있음. 내부 SFTP·강제 명령과 같은 별도 접속 경로는 SSH 정책에서 함께 통제

## 점검 및 조치 사례

### RHEL 10

1. 계정별 로그인 shell 및 서비스 역할 확인

   ```bash command
   getent passwd | awk -F: '{print $1, $6, $7}'
   command -v nologin
   readlink -f /sbin/nologin /usr/sbin/nologin
   ```

2. 로그인이 불필요한 계정의 실제 nologin 경로 지정. `USER`는 해당 서비스 계정으로 대체

   ```bash command
   sudo usermod -s /usr/sbin/nologin USER
   getent passwd USER
   ```

3. 계정의 대화형 로그인 거부 및 해당 서비스의 정상 실행 확인. SSH 키·인증서 또는 토큰이 불필요한 경우 함께 회수
