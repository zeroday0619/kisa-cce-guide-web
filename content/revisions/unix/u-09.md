## 개요

### 점검 내용

그룹 설정 파일(`/etc/group`)에 불필요한 그룹이 존재 여부 점검

### 점검 목적

시스템에 불필요한 그룹이 존재하는지 점검하여 불필요한 그룹의 소유권으로 설정된 파일의 노출로 인해 발생할 수 있는 위험에 대해 대비를 하기 위함

### 보안 위협

계정이 존재하지 않거나 불필요한 그룹이 존재하는 경우, 해당 그룹의 소유로 설정된 파일을 통한 권한 남용 또는 의도치 않은 권한 부여, 보안 감사 및 관리의 어려움 등의 위험이 존재함

## 점검 대상 및 판단 기준

### 대상

RHEL 10, Ubuntu 26.04 LTS, Debian 13

### 판단 기준

- **양호:** 시스템 관리나 운용에 불필요한 그룹이 제거된 경우
- **취약:** 시스템 관리나 운용에 불필요한 그룹이 존재하는 경우

### 조치 방법

기본 그룹 사용자·보조 그룹 구성원·서비스 및 파일 의존성이 없는 불필요한 그룹 제거

### 조치 시 영향

그룹 삭제 및 GID 재사용 시 기존 파일에 잘못된 접근 권한이 부여될 수 있으므로 소유 데이터 인계 후 처리

## 점검 및 조치 사례

### RHEL 10

1. 전체 그룹 및 계정의 기본 GID 확인

   ```bash command
   getent group
   getent passwd | awk -F: '{print $1, $4}'
   ```

2. 삭제 후보 그룹의 기본 그룹 사용자와 파일 소유권 확인. `GROUP`·`GID`·`/srv/data`는 대상 그룹·숫자 GID·점검 마운트로 대체

   ```bash command
   getent group GROUP
   getent passwd | awk -F: -v gid=GID '$4 == gid {print $1}'
   sudo find /srv/data -xdev -gid GID -ls
   ```

3. 서비스의 `Group=`·`SupplementaryGroups=` 및 패키지 사용 여부 확인. 구성원 필드가 비어 있어도 기본 그룹 또는 파일 소유 그룹이면 필요성 판단 후 유지

4. 의존성이 제거된 로컬 그룹만 삭제 후 그룹·파일 권한 재확인. 중앙 그룹은 인증 공급자에서 처리

   ```bash command
   sudo groupdel GROUP
   getent group GROUP
   ```
